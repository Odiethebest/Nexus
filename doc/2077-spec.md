# Nexus Dashboard — Design Spec (Cyberpunk 2077)

## HCI Principles

**Visual Hierarchy** — HIGH priority events must outweigh LOW visually: thicker left bar (6px vs 2px), pink glow, bold type. Strict four-level type scale.

**Affordance** — Publish button spans full panel width at 52px height. Input focus glow expands to 12px so the active field is unmistakable.

**Feedback** — After publish, button briefly shows `[ TRANSMITTED ]` and flashes white→yellow (300ms). New notification cards enter with a glitch animation.

**Readability** — Minimum 12px type. Line-height 1.6. Card content padding ≥ 14px. All accent colours meet ≥ 4.5:1 contrast on dark backgrounds.

### Priority Badge

Outline style, no fill. Per-priority colour with text-shadow and box-shadow glow:

| Priority | Color | Glow |
|----------|-------|------|
| `high` | `#ff2d6b` | `0 0 8px rgba(255,45,107,0.6)` |
| `normal` | `#f5e642` | `0 0 8px rgba(245,230,66,0.5)` |
| `low` | `#00d4ff` | `0 0 8px rgba(0,212,255,0.5)` |

### Notification Card

Left border width, background tint, and glow vary by priority:

| Priority | Border-left | Background | Extra shadow |
|----------|-------------|------------|--------------|
| `high` | 6px `#ff2d6b` | `rgba(255,45,107,0.05)` | `inset -2px 0 20px rgba(255,45,107,0.08)` |
| `normal` | 4px `#f5e642` | `rgba(245,230,66,0.03)` | — |
| `low` | 2px `#00d4ff` | transparent | — |

Card padding: `14px 18px`. Timestamp format: `SYS_TIME: NOW` / `SYS_TIME: 5M`.

### Connection Status

`■` glyph (13px). Connected: yellow + `text-shadow: 0 0 8px rgba(245,230,66,0.8)`. Disconnected: pink + `animation: blink 1s ease infinite` (opacity 1→0.15→1).

## Animations

| Element | Animation | Duration |
|---------|-----------|----------|
| Notification card entry | `glitch-in`: clip-path crop + X jitter + fade | 0.25s |
| Publish button feedback | `flash-white`: bg `#fff` → `#f5e642` | 0.3s |
| Disconnected indicator | `blink`: opacity pulse | 1s ∞ |
| Input focus | box-shadow transition | 0.15s |
| Button hover | glow expand | 0.15s |

```css
@keyframes glitch-in {
  0%   { opacity: 0;   transform: translateX(-4px); clip-path: inset(30% 0 50% 0); }
  20%  { opacity: 0.8; transform: translateX(2px);  clip-path: inset(0% 0 0% 0); }
  40%  {               transform: translateX(-1px); }
  60%  {               transform: translateX(0);    clip-path: inset(10% 0 20% 0); }
  80%  {                                             clip-path: inset(0% 0 0% 0); }
  100% { opacity: 1;   transform: translateX(0); }
}
```
